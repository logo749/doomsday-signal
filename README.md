# 末日信号 · 编队战线（分支 A）

> 试玩：https://logo749.github.io/doomsday-signal/variant-merge-blade/
> 分支：`variant/merge-blade`（从 `main` 拉出）

## 这套分支在验证什么

把主线「滑动 2048 合并」换成 **三连合成 → 编队 → 自动战斗**，对标 Merge & Blade 的结构：
棋盘不再是结算面板，而是 **兵营**——合成的结果直接变成有职能、有站位的作战单位。

| 元素 | 规则 |
| --- | --- |
| 棋盘 | 4×4，点击两个 **相邻** 格子交换（无滑动） |
| 合成 | 横向/纵向连成 3 个 **同类同阶** → 合成高 1 阶，入伍 |
| 兵种 | 刀兵（近战）、盾兵（高血量前排）、枪兵（远程后排）、医兵（治疗最低血量） |
| 编队 | 前排 3 格 / 后排 3 格；点卡片可在两排之间换位 |
| 战斗 | 全自动：兵种按冷却攻击，怪物按倒计时打前排最残血的单位 |
| 压力 | 阵亡不回血；每波结束全队回 30%，杀穿 9 波即胜利 |
| 满员 | 队伍 6 人满编时，新兵替换最弱的单位 |

## 与主线的差异

- 操作从「滑动整盘」变成「点选交换」，节奏更慢、更像解谜。
- 胜负不取决于棋盘锁死，而取决于 **队伍构成是否克制这一波怪**。
- 核心决策：先合哪条线、谁上前排、什么时候换掉残血单位。

## 怎么跑

- **H5（本分支的主路径）**：打开 `index.html`，需 Chrome / Edge / Safari 16+（依赖原生 `DecompressionStream`）。
- **抖音小游戏**：本分支只提供 H5 原型，平台构建（`game.js / game.json / project.config.json`）仍以 `main` 为准。

## 本分支的构建方式

为避免仓库里出现两份重复的大文件，本分支把原型打成压缩载荷：
`js/core.b64.1` ~ `js/core.b64.4` 是 gzip+base64 片段，`js/boot.js` 在浏览器端拼回、解压后执行。
可维护的源码同构于本地工作区 `variant-merge-blade/`，后续可合并回 `main` 的 `variants/` 目录再做平台适配。

## 说明

- 系统结构借鉴 Merge & Blade，**代码、美术、文案全部自研**：画面为零素材 Canvas 绘制 + 系统 Emoji，无版权风险。
