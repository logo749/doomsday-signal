# 末日信号 · 合并生存

> 在线试玩（GitHub Pages 自动部署）：https://logo749.github.io/doomsday-signal/
> 仓库：https://github.com/logo749/doomsday-signal
> 推送 main 分支即触发 `.github/workflows/deploy.yml` 自动部署。

末日生存主题的「类 2048 组合消除升级」竖屏小游戏。顶部是战斗场景（幸存者 vs 感染体），底部是 4×4 合并棋盘：滑动合并物资，食物药品回血、武器自动攻击怪物、装甲给护盾；怪物按步数倒计时反击。撑过 3 章 9 波感染体，摧毁母体核心，发出撤离信号——含完整开场 / 章节 / 结局剧情。

- 规则集 ID：`doomsday-merge-v1`（全部数值集中在 `js/game-core.js` 顶部 `RULESET`，唯一数值来源）
- 逻辑分辨率：750×1334 竖屏，等比缩放适配任意屏幕（黑边填充）
- 技术：纯 Canvas 2D，零依赖、零外部资源（图标用系统 Emoji），抖音小游戏与 H5 共用同一核心

## 运行方式

### H5 试玩（已完整实测）
直接用浏览器打开 `index.html`，或本地起服务：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/index.html
```

- 操作：触屏滑动 / 鼠标拖拽 / 键盘方向键与 WASD；空格/回车推进剧情
- 调试：URL 加 `?seed=42` 固定随机种子；控制台 `window.__game.debug` 提供状态读取与局面设置（`state()/setBoard()/setMonsterHP()/setPlayerHP()/setAttackIn()/setShield()/move()/tap()`）

### 抖音小游戏
1. 打开抖音开发者工具 → 导入项目 → 选择本目录（`compileType: game`，竖屏已在 `game.json` 配置）
2. 在 `project.config.json` 填入你自己的 `appid`（当前为空，未编造）
3. 入口 `game.js` 通过 `tt.createCanvas / tt.getSystemInfoSync / tt.onTouchStart / tt.onTouchEnd / tt.getStorageSync / tt.setStorageSync` 接入，核心逻辑与 H5 完全一致

> 注意：抖音入口代码按平台标准 API 编写，但开发环境无抖音开发者工具，**未在抖音运行时实测**；H5 端已全路径实测（见下）。上架前请在开发者工具与真机预览各跑一遍。

## 玩法规则

### 合并链（11 级）
| Lv | 物资 | 合成效果（合成到该级时） |
|---|---|---|
| 1 | 🔩 废料 | 基础块（90% 生成 Lv1，10% Lv2） |
| 2 | 🥫 罐头 | 伤害 1，回血 3 |
| 3 | 💧 净水 | 伤害 2，回血 4 |
| 4 | 💊 药品 | 伤害 3，回血 10 |
| 5 | 🔪 刀刃 | 伤害 6 |
| 6 | 🔫 枪械 | 伤害 10 |
| 7 | ⛽ 燃料 | 伤害 16 |
| 8 | 🔋 电池 | 伤害 24 |
| 9 | 📻 电台 | 伤害 36 |
| 10 | 🛡️ 装甲 | 伤害 54，护盾 +30（上限 60） |
| 11 | 📡 信号塔 | 伤害 80（满级，不可再合并） |

- 计分：2048 式，合成到 Lv L 得 `2^L` 分；最佳分本地持久化
- 玩家生命 100；护盾优先抵挡怪物攻击
- 每次有效移动：怪物攻击倒计时 -1，归零时怪物攻击（伤害见下表），随后重置
- 击杀怪物：搜刮物资 +15 HP，保留棋盘进入下一波
- 失败：生命归零，或棋盘锁死（含换波后检测，无软锁）；胜利：击败第三章 Boss

### 章节与怪物（3 章 × 3 波）
| 章 | 场景 | 怪物（HP / 攻击 / 攻击间隔步） |
|---|---|---|
| 一 | 废弃地铁 | 感染鼠群 20/4/7 · 游荡丧尸 35/6/6 · 变异猎犬 50/8/6 |
| 二 | 市立医院 | 蛛群巢穴 65/9/6 · 感染医生 85/11/5 · 血肉聚合体 110/13/5 |
| 三 | 地下实验室 | 安保机甲 140/15/5 · 变异暴君 180/18/4 · 母体核心 240/22/4 |

### 剧情
病毒爆发第 217 天，幸存者「阿岩」收到电台里「老周」的讯息：北区实验室仍在发信号。沿地铁→医院→实验室推进，章间对话揭示「疫苗」真相是培育母体；击败母体后迎来直升机撤离结局。开场 4 句、章间 2+4 句、结局 2 句，点击推进。
